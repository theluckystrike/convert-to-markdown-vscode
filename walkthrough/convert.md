# Convert a file

Right-click a file in the Explorer and pick Convert to Markdown. You can also right-click an editor tab, or run Convert to Markdown from the Command Palette while the file is open.

Formats: PDF, Word (.docx, .docm, .doc), PowerPoint (.pptx), Excel (.xlsx, .xls, .ods), CSV, TSV, HTML, EPUB, OpenDocument text (.odt) and RTF.

The converter runs inside VS Code. Nothing is installed and nothing is sent anywhere.
