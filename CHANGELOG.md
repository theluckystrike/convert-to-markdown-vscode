# Changelog

## 0.1.0

- First release. Convert to Markdown for PDF, Word (.docx, .docm, .doc), PowerPoint (.pptx), Excel (.xlsx, .xls, .ods), CSV, TSV, HTML, EPUB, ODT and RTF files, from the Explorer, an editor tab or the Command Palette.
- Copy as Markdown.
- PDF: headings from font sizes, paragraphs, lists, simple tables, two-column pages, running headers and page numbers removed.
- PowerPoint: one section per slide with its title, bullets, tables, pictures and speaker notes.
- Damaged, password-protected and old PowerPoint 97-2003 files get a message that says what to do. Big files show progress with a Cancel button.
- Zovo Pro tools, 3 free tries each: Convert a whole folder, Extract images, LLM-ready output.
- Convert a whole folder: files in one folder that share a name, such as report.pdf and report.docx, become report.pdf.md and report.docx.md, so every file is converted. Only a .md that was there before the run counts as "already exists".
- "More free viewers" lists the Zovo extensions most related to this one. Picking one opens its Marketplace page, where you choose to install it.
- The walkthrough ends with a step that links free Zovo extensions for the files that often come with documents. A link opens the extension page; nothing installs on its own.
- The footer link "Zovo Pro, USD 19" and the Marketplace Sponsor button open the Zovo Pro tier (USD 19 once, for every Zovo extension).
